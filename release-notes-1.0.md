# Sonarus Helper 1.0

Client-side Fabric helper for the Sonarus Minecraft server.

When connected through `play.sonarus.win`, pressing **Enter** or **Numpad Enter** on a Minecraft Dialog API screen activates the visible **«Войти»** button. The helper does nothing on other servers.

## Supported Minecraft versions

- 1.21.6
- 1.21.7
- 1.21.8
- 1.21.9
- 1.21.10
- 1.21.11
- 26.1
- 26.1.1
- 26.1.2
- 26.2
- 26.3

Choose the JAR whose filename contains your exact Minecraft version and place it in the client `mods` folder.

# Sonarus Helper

Sonarus Helper делает игру на **Sonarus** удобнее.

После ввода пароля можно просто нажать **Enter** или **Numpad Enter** — мод сам нажмёт кнопку **«Войти»**.

В моде также есть удобные настройки, уведомления Windows и проверка обновлений. Все функции работают только на нашем сервере.

В будущем в Sonarus Helper будут появляться и другие полезные возможности.

## Возможности

- быстрый вход по **Enter**;
- отдельное окно настроек по **H** или команде **/shelp**;
- уведомления, если вас упомянули в чате;
- уведомления о новых версиях Sonarus Helper;
- возможность отключить ненужные уведомления.

## Установка

- Скачайте версию мода под свою версию Minecraft.
- Поместите файл в папку **mods**.
- Запустите игру и зайдите на **play.sonarus.win**.

Чтобы открыть настройки, нажмите **H** или используйте **/shelp**.

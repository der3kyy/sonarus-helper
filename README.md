# Sonarus Helper

Клиентский мод для сервера **play.sonarus.win** (Fabric).

## Возможности

- Вход по Enter или Numpad Enter в окне авторизации.
- Запоминание и автозаполнение пароля по желанию игрока.
- Проверка и скачивание обновлений.
- Настройки по команде `/shelp`.

## Как сохранить пароль

Зайдите на сервер и откройте `/shelp`. Включите «Запоминать пароль при входе» и «Подставлять сохранённый пароль». При следующем входе введите пароль и нажмите «Войти». После этого Helper сможет заполнять поле входа для того же ника. Подтверждать вход нужно самостоятельно.

Пароль хранится только на вашем ПК, в зашифрованном виде средствами Windows. На сайт он не отправляется; при авторизации Minecraft передаёт его серверу обычным способом. Сохранение пароля по умолчанию выключено и работает только в Windows. Удалить сохранённый пароль можно в `/shelp`.

## Установка

Скачайте JAR под свою версию Minecraft, положите его в папку `mods` и подключитесь к `play.sonarus.win`.

Для Minecraft 1.21.x нужна Java 21, для Minecraft 26.x — Java 25.
